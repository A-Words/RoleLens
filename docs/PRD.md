# RoleLens 第一版

Local-first 个人求职工作台（当前仅实现 Local Mode）：导入文字型 PDF、DOCX、Markdown、TXT 或文本，经审阅确认建立求职档案。以真实经历为依据分析粘贴的 JD，追问缺口，生成三种中文招呼语和可编辑、可导出 PDF 的简历。

档案覆盖个人背景、教育、工作、项目、技能、成果、联系方式、求职偏好。所有 AI 提取和对话修改先进入草稿；用户确认后才能用于生成。资料可编辑、排除、删除，来源和版本可查。职位下的内容不覆盖原始事实。

不实现多用户、自动投递、网站抓取、仓库分析或自由排版。Local Mode 为单用户、无需账号、127.0.0.1、SQLite 和本地文件。Hosted Mode 仅保留配置与密钥存储的替换边界，不实现多租户、认证或 PostgreSQL。设置页配置模型与可选 Langfuse，Nitro 保存和使用密钥；.env 用于启动配置及开发 override。默认本机监听，云端模型仅接收相关资料，联系方式由本地渲染加入。

验收：导入→确认→JD→追问/跳过→生成→编辑→PDF；不同 JD 选择不同经历，不编造指标或贡献；检查持久化、工具调用、来源、重试、删除/排除、中文分页。无真实模型配置时明确标记未完成云端验收。
