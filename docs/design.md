# 工作台视觉规范

参考 `docs/design-reference.png`（内置 Image Gen 生成的 UI 概念，仅用于设计，不是应用数据）。

侧栏约 216px，宽屏内容以资料列表和右侧对话栏组成。背景 #f8f9fb，面板白色，正文 #18213a，次级文字 #64748b，主色 #4f46e5；边框 #e2e8f0，圆角 10px。正文 14px，标题 30px，控件明确字号，使用本地中文字体和 Lucide 线条图标。

导航：资料库、职位工作台。资料库主标题：个人资料库；副标题：整理真实经历，让每一次表达都有依据。主要操作：导入资料、整理为草稿、确认入库。空状态不使用示例经历填充；新增类别、模型配置提醒和历史版本属于已授权产品流程所必需的补充。

移动端侧栏转顶栏，双栏折叠为单栏。职位详情沿用同一面板、边框和排版系统，包含 JD、分析对话、证据和结果编辑。
