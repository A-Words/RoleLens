# 第一版验证记录

日期：2026-09-05。环境：Windows、Node.js 24.18.1、Nuxt 4.5.2。全部使用合成测试资料，无用户个人资料。

## 结果

- `npm run typecheck`：通过。
- `npm run test`：3 个测试文件、14 项通过。
- `npm run build`：通过，Nitro node-server 产物可启动。
- `npm run test:e2e`：2 项通过，在生产构建上执行。
- `npm run format:check`：通过。

测试包括：草稿确认与重复确认拒绝；旧版本编辑冲突；对话修改仅生成草稿；排除、联系方式与删除资料不进入检索；SQLite 关闭重开后恢复追问；不同 JD 检索不同项目；模型失败后重试；核验失败拒绝保存并重新生成；并发执行拒绝；中断检查点修复运行状态；生成幂等与历史事实快照；中文文档提取和长 PDF 分页。

浏览器自动化完整路径：上传 Markdown → 确认入库 → 刷新仍存在 → 创建职位 → 分析/真实工具调用 → 刷新恢复追问 → 回答 → 生成 → 手动编辑并保存 → 下载 PDF → 提取中文确认内容和页数 → 移动端检查 → 删除版本并刷新确认不再出现。另验证跨站写入与非法输入被拒绝。

内置浏览器独立复核：资料库初始状态、手动录入表单、对话整理草稿、确认资料、创建职位、开始分析、跳过缺口、生成简历和三种招呼语、点击复制后出现“已复制”。此复核使用隔离 `.qa/cua` 数据和本地模拟模型服务。

## 视觉核对

使用内置 Image Gen 生成 [设计参考](design-reference.png)，简报与设计规范见 [design.md](design.md)。内置浏览器优先检查实际页面；Playwright 用于可重复的端到端测试、下载断言和截图，没有替代为静态原型。

使用 `view_image` 检查设计参考及最终渲染截图。桌面按参考原生尺寸 1505 × 1045 验证，移动视口 390 × 844；页面无横向溢出，无浏览器页面异常。

| 检查点 | 结果与有意差异 |
| --- | --- |
| 信息布局 | 保持固定侧栏、中央事实列表和右侧对话/草稿两栏；空库与单条数据按实际条目收缩，不伪造参考图中的五个项目 |
| 主色和面板 | 浅灰背景、白色面板、靛蓝主操作、细边框和圆角一致，无装饰性图片 |
